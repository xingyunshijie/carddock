已完成

  • 86 项 Python 自动测试通过，保留原有访问密钥、管理员认证、目录浏览、部署保护、读卡器发现与暂停取消的测试，并新增桌面规则同步测试。
  • 覆盖全景目录与拍摄组、内部元数据、延时/代理/索尼缩略图/RED 结构、命名与筛选、多目标与读取来源、重复导入与缺失修复、冲突保护、主盘篡改、目录身份、队列冻结与重试、预设、报告/MHL XML 转义及内容校验完成信号。
  • SHA-256、MD5、XXHash64、BLAKE3 独立已知值与项目内官方 BLAKE3 边界向量通过。
  • 新增 HTTP 检查：未认证拒绝、跨域请求拒绝、目录越界拒绝、新建目标目录、提交/重试/删除、报告与预设接口。
  • 在 ego-browser 中完成登录、数据源分类预览、目标目录选择、新建归档目录、主盘加备份拷贝；页面与报告均显示完成。
  • 构建2取消生成器流程，提供完整 Compose 配置与教程内复制入口。新增密码认证测试：正确/错误密码、中文符号、禁止默认占位值、会话过期、重启失效、退出登录、旧密钥不覆盖配置密码、跨域登录拒绝。
  • 使用 Docker 官方 Compose 独立客户端对示例及完整部署配置执行 config 校验通过；这项检查不需要 Docker Engine，不表示容器已经运行。
  • Linux x86_64 与 ARM64 的 CPython 3.12 原生依赖，均使用 pip 离线 dry-run、完整哈希锁与架构匹配检查通过。
  • JavaScript 与启动脚本语法检查通过；官方基础镜像多架构摘要、Linux amd64/arm64 条目已从 Docker Registry 核实。
  • 发布 ZIP 与文件级 SHA-256 清单在打包时检查，不包含开发状态、真实密钥、NAS IP、旧专用 Compose 或用户数据。

  • 用可重复素材测试全景、RAW/JPG、延时与代理分流，核对主盘与备份哈希。
  • 重复导入，确认同内容跳过；删掉测试备份中的一份，确认重试补回。

复验命令（供维护者）

python3 -m pip install -r requirements.txt
python3 -m unittest discover -s tests -v
node --check app/static/app.js
sh -n runtime/start.sh
docker compose -f compose.project.json config --no-interpolate

完整 Docker 启动和 preflight.py 需在 NAS 的实际容器里执行，不在 Mac 上伪造通过。
