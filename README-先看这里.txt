影像归仓 NAS 1.5.2 · 通用安装

不需要上传源码包，也不依赖某个用户的NAS共享路径。

1. NAS 的 Docker / Container Manager 中创建项目，名称填写 carddock。
2. 粘贴 compose.project.yaml，修改 AUTHENTICATION_PASSWORD 为自己的登录密码后部署（至少8位，最多256位，不能保留示例文字）。
3. 访问 http://NAS_IP:18080，输入设置的密码。
4. 首次进入先选择拷贝主目录，按需添加备份，再点击“保存并进入”。

要显示NAS全部共享文件夹，请先按“共享文件夹安装.html”运行一次授权安装；工具读取当前NAS自己的共享定义，不使用固定名单。

默认文件夹模式使用项目内 inbox（待导入）、archive（归档）和 data（设置与历史）。
保存后的目录可以继续在软件中修改，备份留空即只拷贝主目录。
新增项目外共享目录、独立硬盘和读卡器时，先按实际NAS路径开放Docker映射。
项目文件夹包含素材和设置，不能当成普通程序文件夹删除。

完整说明：NAS安装说明.html。已有用户升级请先看 UPDATE.html。
本ZIP用于源码和依赖备份；程序镜像支持amd64/arm64，两种架构均通过实际容器测试。
不同品牌NAS的权限和热插拔仍需实机验收。
