影像归仓 NAS V1.0 构建2

完整安装说明：NAS安装说明.html

先上传并解压整个程序目录到说明指定的位置。

1. 创建项目：NAS 的 Docker → 项目 → 创建，项目名 carddock。
2. 将说明中的整段配置完整粘贴。
3. 端口：默认18080:8080，冲突时只改左边。
4. 认证：保持 AUTHENTICATION_ENABLED=true，将 AUTHENTICATION_PASSWORD 改成自己的12位以上密码。

访问 http://NAS_IP:18080，用自己设置的密码登录，单用户模式，无需用户名。
主盘和备份在程序里选择；备份留空即只拷主盘。旧版升级先看 UPDATE.html。

本包带程序与双架构校验依赖，首次仍需拉取官方Python运行镜像。
没有在此开发机启动 Docker 或完成 NAS 实机认证。
