# 绿联 NAS 安装（Docker 图形界面）

本指南需要已安装 Docker 应用。下载的是测试版，请先用测试卡验收。路径和账户 ID 以你的 NAS 为准；示例不代表所有型号的默认配置。

1. 在 Releases 下载 `carddock-版本-install.zip`，解压到电脑。源程序安装包适用于两种架构。
2. NAS 文件管理中创建主导入文件夹、可选备份文件夹，以及独立 `carddock-state`。给运行账户读写权限；读卡器目录给读取权限。在 NAS 查看账户 UID/GID（管理员终端可用 `id 用户名`）。
3. 核实 NAS 外接存储自动挂载父目录。部分绿联为 `/mnt/@usb`；不要填写当前卡片 `/mnt/@usb/sde1`。父目录不存在时部署应失败，而不是自动建一个空目录。
4. 用电脑浏览器打开包内 `setup.html`，填写目录、UID/GID和端口，保存随机访问密钥，下载 `compose.yaml`。额外存储区可以加入其他共享文件夹，使网页目录选择器可逐级浏览。不要映射整个 `/` 或系统目录。
5. NAS Docker → 项目 → 创建，上传生成的 Compose 文件。部署会拉取 `ghcr.io/xingyunshijie/carddock:版本`。配置含密钥，不要公开分享。
6. 打开 `http://NAS局域网IP:18080`（或自选端口），输入刚才保存的密钥。选择主文件夹和可选备份，保持 SHA256，先手动导入少量测试素材。
7. 测试通过后，选择自动模式并保存。以后插卡由 NAS 挂载后，应用识别并运行。安全弹出仍需在 NAS 执行。

## 镜像下载失败 / 离线安装

从同一 Release 下载与你 NAS 架构匹配的 `carddock-版本-amd64.tar.gz` 或 `carddock-版本-arm64.tar.gz`，解压得到 tar；在 Docker → 镜像 → 导入中选择。生成配置时将镜像字段改为 `carddock:版本-amd64` 或 `carddock:版本-arm64`。不熟悉 CPU 架构时查看 NAS 系统信息；不能交换使用两种镜像。

## 首次验证

需要验证源目录和插入卡的子挂载只读。可在 Docker 容器终端中执行 `python /app/preflight.py`；插拔新卡后再执行一次。若报错不要绕过检查。更完整的管理员检查及终端安装见 [通用指南](../PORTABLE-INSTALL.md)。

检查两份副本校验成功、重复导入不重复写入、暂停/继续/终止正常；最后测试拔插与 NAS 重启。没有实测前不要把“容器正在运行”当成“自动插卡已验证”。

## 更新

保存手动模式并等当前任务结束。备份原 Compose 和状态目录；在配置中只修改镜像版本，重新部署。保留路径、账户、密钥和原状态目录。失败时改回原镜像版本；回退不删除已导入素材。

不要在拷贝时自动更新容器。遇到问题记录旧版与新版版本号、系统版本及脱敏日志，提交 Issue。
