NAS V1.0 构建2：功能同步说明

以当前 Mac 构建21和 Windows 构建4的实际代码为参照，升级原 NAS V0.11 核心。新包未操作正在运行的 NAS 服务，也不会移动旧归档。

桌面改进NAS 新版实现
大疆 PANORAMA独立“全景序列”，保留拍摄组、内部目录和所有可选范围内的文件，不拆 RAW/JPG
RAW/JPG 及伴随文件普通素材分格式，完整模式同名伴随文件优先跟随 RAW
延时摄影目录简化保留组号，再分 RAW/JPG；保护原编号，不把普通连号当延时
视频代理新增 LRF；专用目录/命名识别、直接平铺、可排除，含明确关联伴随文件
索尼视频缩略图全部扫描范围排除专用路径内 JPG/JPEG，不按大小猜测
RED RDC保留容器结构和分段命名
先拷贝后校验每个目标先写完所有新文件，再集中校验与发布；不会将未验证文件记录为有效副本
拷贝数量一直为0新增独立的拷贝阶段、校验阶段计数；每写完一个文件增加拷贝数量
速度和剩余时间真实写入量、滚动写入速度、平均速度、分秒时间；拷贝剩余估计明确不含未进行的校验
校验算法SHA-256、MD5、XXHash64、BLAKE3；快速模式只有大小检查，已有文件仍重新哈希后去重
主盘接力备份本次已验证清单从主盘生成多份备份，保存实际读取来源；可选择各目标直接读源
时间属性兼容目标最终复核核对对象/大小/内容，避免只因时间属性刷新而误报；源与主盘作为后续读取源时仍严格保护
文件系统兼容发布优先硬链接独占发布，不支持时使用 O_EXCL 创建并复制，仍复核内容，绝不静默覆盖
冲突处理普通素材保留两份、跳过或显式覆盖；默认保护全景、延时、代理与 RED 原名
模板和筛选日期/项目/设备/机位/卡号/来源目录；普通文件名模板；修改日期与扩展名筛选
RAW/JPG/XMP 编号匹配文件共享命名序号；全景、延时、代理、RED 不被模板改名
设备概览目录/格式推测、常见 JPEG/TIFF RAW 的有限 EXIF Make/Model 抽样，混合设备概览；仅有 DJI 文件名时类型待确认
队列与重试手动排队、冻结路径与选项、串行执行、暂停/继续/取消、原规则重试；删除记录不删素材
任务与卷身份执行前核对来源、目标目录身份；源清单变化、对象替换、大小或内容变化停止任务
预设保存、载入、JSON 导入/导出；载入预设不会自动开启后台导入
记录和报告JSON、TXT、传输日志、校验清单、兼容算法的基础 MHL 1.1、可打印为 PDF 的独立 HTML 报告
外观、品牌和提示浅色、墨绿、跟随系统；云景数码影画署名；网页保持打开时可选完成/警示提示音
帮助与版本软件内更新说明、离线安装教程、创建 Docker 项目教程和完整可粘贴配置和登录密码认证

平台差异与当前范围

  • NAS 使用网页与后台服务，保留自动发现已挂载读卡器和自动导入；无需 Mac 或 Windows 客户端保持打开。
  • 默认运行方式不安装 ExifTool。JPEG/经典 TIFF 类 RAW 可读有限机型标签，其他格式以目录与格式推测；可选 Dockerfile 构建路线提供 ExifTool 增强，不承诺读取所有机型或视频元数据。
  • NAS 文件列表提供数量、容量、分类和路径预览，不包含 macOS Quick Look 或系统级通用 RAW/视频解码；单文件导入仍按 NAS 版的目录来源工作流处理。
  • PDF 通过导出 HTML 后由浏览器打印保存，未把 macOS 原生 PDF 导出代码搬进容器。
  • 容器不直接卸载 NAS 设备；任务完成后仍使用 NAS 系统安全弹出。桌面账号的商业支付/激活目前没有接入此 NAS 包；不会把预留的 NAS 权益描述为已上线收费功能。
  • 官方 Python 运行镜像已固定多架构摘要，包内附带 Linux amd64/arm64 依赖。没有 Docker Engine 的当前开发机只能验证逻辑、页面、配置和依赖；容器启动、NAS 卷身份、权限与 USB 热插拔仍需实机确认。

构建2：安装和认证

说明结构与提供的 NAS 教程一致。项目配置启用 AUTHENTICATION_ENABLED，安装人员自行填写 AUTHENTICATION_PASSWORD。程序实际使用该密码登录并签发有时效的随机登录凭据；退出或重新部署后失效。显式密码模式不会被旧访问密钥文件覆盖。
